# ⏰ Ontime — Public Beta v0.1.0

> **The first public release of Ontime.** Built with love, tested with care, released with excitement.

---

## 🎉 What's in this release

This is the **Public Beta v0.1.0** — the first version of Ontime available to the world. It contains the full suite of core features that have been in active development.

### ✨ Features included

**⏰ Smart Alarms**
- Gentle Wake (gradual volume ramp)
- Text-to-Speech time announcements (male/female voice)
- Weather Reminder (requires location permission)
- Extra Loud mode with delayed audio sequence
- Progressive snooze with visual timeline
- Label reminder (reads alarm label aloud)
- Full Firebase Firestore cloud sync

**🎯 Focus Timer**
- Pomodoro, Stopwatch, and Custom technique modes
- Ambient sounds: Rain, White Noise, Brown Noise, Forest, Ocean, Café, Lo-fi
- Streak tracking and daily goal
- App usage statistics (UsageStatsManager)
- Distraction counter

**🛡️ App Blocker**
- Session-based app blocking (Accessibility Service)
- DNS-proxy adult content filter (local VPN, no data leaves device)
- Device Admin protection (prevents easy uninstall)

**📅 Calendar**
- Google Calendar sync
- Holiday overlays (national + religious)
- Event reminders with SMS invite support
- Month / Week / Day views
- Attendee management

**🌸 Period Tracker**
- Cycle logging and prediction
- Symptom and mood tracking
- Smart reminders
- 100% offline — data never uploaded

**🌗 Themes**
- Deep Space Dark theme
- Pearl & Amethyst Light theme
- System / Light / Dark toggle in Settings

**🔒 Security**
- PIN + Biometric App Lock
- Cloud sync with last-write-wins strategy

## ⬇️ How to Install

1. Download `Ontime-v0.1.0-beta.apk` below
2. Open the file on your Android device
3. Enable **"Install from Unknown Sources"** if prompted
4. Tap **Install** → Sign in with Google → You're ready! 🚀

**Requirements:** Android 8.0+ · ~50MB storage

## ⚠️ Known Limitations (Beta)

- This is a **beta release** — some rough edges may exist
- Weather Reminder requires OpenWeatherMap API key (included in this build)
- Some screens may still appear in dark mode regardless of theme setting (being fixed)
- No automatic updates — check this page for new releases
